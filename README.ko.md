# 풀노드 첫걸음 강의 자료

[English](README.md) | [한국어](README.ko.md)

풀노드를 직접 돌려보며 비트코인의 규칙과 네트워크를 이해하는 강의 자료를 모아 둔 저장소입니다. 슬라이드는 동구리(Dongguri-Jun)가 만들었고, PDF로 바로 내려받아 강의나 개인 학습에 사용할 수 있습니다.

두 PDF는 각각 32쪽의 1920×1080 슬라이드입니다. 한국어 자료는 서울 행사, 영문 자료는 말레이시아 행사에 맞춰 제작된 버전입니다.

## 다루는 내용

슬라이드는 비트코인과 풀노드의 관계에서 시작해, 풀노드를 운영하는 이유와 시작 방법으로 이어집니다. 하드웨어 선택, 직접 조립과 완제품의 차이, 구현체 설치, 초기 동기화(IBD), 네트워크 참여를 설명합니다. 뒤에서는 Electrs를 통한 지갑 연결과 Coconut Wallet·BlueWallet 보기 전용 연결, Tailscale·Tor, Lightning, 솔로 채굴을 소개합니다.

강의는 고사양 장비나 개발 지식이 있어야만 시작할 수 있다는 전제 대신, 관심 있는 단계부터 직접 확인해 보는 흐름으로 구성했습니다. 풀노드가 검증하는 것과 지갑·채굴자가 맡는 일을 구분하고, 조회 경로의 프라이버시와 온체인 공개성·IP 프라이버시가 서로 다른 문제라는 점도 함께 다룹니다.

## 참고 자료와 출처

풀노드의 개념과 운영 주제를 정리할 때 [Plan ₿ Academy Bitcoin Educational Content 저장소](https://github.com/PlanB-Network/bitcoin-educational-content)를 참고했습니다. 특히 다음 공개 자료가 주제와 개념을 확인하는 데 도움이 됩니다.

- [BTC202 English course](https://github.com/PlanB-Network/bitcoin-educational-content/blob/dev/courses/btc202/en.md)
- [BTC202 Korean course](https://github.com/PlanB-Network/bitcoin-educational-content/blob/dev/courses/btc202/ko.md)
- [Plan ₿ Academy 저장소 라이선스](https://github.com/PlanB-Network/bitcoin-educational-content/blob/dev/LICENSE.md)

이 저장소의 PDF는 제목, 제작자, 행사, 구성과 표현을 자체적으로 갖춘 Dongguri-Jun의 강의 슬라이드입니다. Plan ₿ Academy의 공식 번역본이나 공식 배포본으로 표기하지 않습니다. 두 자료군은 풀노드, 지갑 연결, Umbrel·Electrs, 동기화와 네트워크 참여처럼 겹치는 주제를 다루지만, PDF에서 Plan ₿ Academy 원문을 직접 번역했다는 표시는 확인되지 않았습니다.
